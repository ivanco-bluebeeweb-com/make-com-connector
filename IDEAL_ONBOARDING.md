# Make.com Connector — идеальный первый запуск

Источник: `ONBOARDING_FIRST_LAUNCH_STANDARD.md`. Целевой пользователь: no-code/ops-
специалист на Make (бывший Integromat).

## 1. Credential type
API key (одно поле).

## 2. Идеальный флоу
1. **Первое открытие** — `Empty` со ссылкой "avatar > Profile > API tab > Add token".
2. **Форма** — api_token (password-type) с лейблом.
3. **Team/organization selector** — Make организован по Teams внутри Organizations —
   идеально: явный двухуровневый выбор ПОСЛЕ подключения токена, ДО показа сценариев
   (`select_team` уже есть как функция — довести до первого экрана).
4. **После выбора команды** — список сценариев со статусом (активен/на паузе) и
   последним запуском сразу.
5. **Failed scenario emphasis** — сценарии с недавними ошибками выполнения должны
   визуально выделяться в списке (не одинаковый вид у всех).
6. **Ошибка "no teams found"** — если у токена нет доступа ни к одной команде —
   конкретное объяснение, не пустой список без причины.
